Blinkit Sales Analysis Dashboard
Project Overview
This project is an interactive Blinkit Sales Analysis Dashboard
built using Microsoft Power BI. It presents key sales and outlet
performance insights through visual reports, KPI cards, charts, and
interactive filters.

The dashboard is organized into two report pages:
1. Blinkit Sales Overview
This page gives a high-level view of overall sales performance and
outlet trends.

Key metrics - Total Sales - Average Sales - Total Items - Average
Rating

Visual analysis - Sales by Fat Content - Sales by Outlet Location
Tier - Sales by Outlet Size - Sales by Outlet Establishment Year - Sales
by Outlet Type

Available filters - Outlet Year - Item Type - Fat Content - Outlet
Location Type
2. Items and Outlet Analysis
This page focuses on item categories and outlet-level performance.

Key metrics - Unique Items - Average Item Weight - Average Item
Visibility - Top Item Type

Visual analysis - Top 8 Item Types by Sales - Sales by Outlet
Location Tier - Outlet Details, including sales and average rating -
Item Type sales comparison across outlet types

Available filters - Outlet Type - Outlet Size - Rating
Dashboard Highlights
- Interactive slicers to filter the report and explore different
  views.
- KPI cards for quick performance tracking.
- Charts to compare sales across item categories and outlet
  characteristics.
- Outlet-level and item-level breakdowns to support business analysis.
Tools Used
- Microsoft Power BI --- dashboard development and data
  visualization.
Project Purpose
The goal of this project is to explore Blinkit sales data, understand
how sales vary across item types and outlet characteristics, and present
the findings in an easy-to-use interactive dashboard.
Created as a Power BI data analytics project.
